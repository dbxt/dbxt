## Building

- [TechDrift](https://techdrift.app/) - Tracks what is gaining traction in tech. A topic is promoted only when it holds up across independent sources over time, and every claim links to its evidence.
- [GamingDrift](https://gamingdrift.app/) - The same evidence-first approach, for gaming.
- [SportsDrift](https://sportsdrift.app/) - The same, for sports.

One shared engine runs all three, built and operated solo with AI agents. Stack: Node.js, Postgres, and a self-hosted LLM for bounded advisory tasks. [Case study](https://davidwaynebaxter.com/ai/techdrift/).
